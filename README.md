# Asbestos Consultancy Expert (ACE)

ACE's static business website, prepared for GitHub Pages. This initial draft uses plain HTML and CSS rather than Remix 3; no server or package dependencies are required.

## Preview and build

With Node.js installed, run `node scripts/serve.mjs` and open http://127.0.0.1:4173. Run `node scripts/build.mjs` to create the publishable `dist` folder.

## GitHub Pages

In the repository's Settings → Pages, select **GitHub Actions** as the source. The included workflow builds and publishes when changes are pushed to `main`, or when run manually. Relative asset links support the `/Website/` project path and a future custom domain.

## Before publishing

The confirmed contact details are 07962 608931 and Info@asbestosce.com, covering all of Scotland. Review the descriptions and confirm that each matches ACE's actual work. No accreditations, licences, testimonials or qualifications have been assumed.
